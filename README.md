
# 🎵 Spotify Clone

A modern and responsive **Spotify Clone** built using **HTML, CSS, and JavaScript**.  
This project recreates the core frontend experience of Spotify with interactive music controls and a clean user interface.

---

## 🚀 Features

- 🎧 Play & Pause Songs
- ⏭ Next / Previous Controls
- 📀 Interactive Music Cards
- 🎚 Music Progress Bar
- 🔊 Volume Controls
- 📱 Fully Responsive Design
- ⚡ Smooth UI Animations
- 🎨 Spotify Inspired Interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome Icons

## ⚙️ How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/your-username/Spotify-Clone.git
```

2. Open the project folder

```bash
cd Spotify-Clone
```

3. Run the project

Simply open `index.html` in your browser.
